# Module static

## Description

Ce répertoire contient les fichiers statiques utilisés pour l'interface de la calculatrice web.

## Fichiers principaux

- `style.css` : définit la mise en page, les couleurs, les dimensions et l'apparence des boutons de la calculatrice.

## Dépendances et hypothèses

- Le fichier CSS est chargé par `index.html` à l'aide de Flask.
- L'affichage des styles dépend d'un navigateur compatible avec CSS.
